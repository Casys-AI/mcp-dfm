# Changelog

All notable changes to `@casys/mcp-dfm` are documented here.

## [0.1.0] — 2026-08-05

### Added

- `dfm_check_envelope` — bounding box (X/Y/Z in mm) and optional mass against a
  declared print volume. Volume computed from the closed STL surface mesh via the
  divergence theorem. Mass requires an explicit `density_kg_m3`.
- `dfm_check_overhangs` — surface overhang detection: STEP → surface STL via Gmsh,
  then per-triangle angle between outward normal and the declared `build_direction`.
  Reports total overhang area and bounding boxes of violation clusters.
- `dfm_check_min_thickness` — minimum wall thickness via bidirectional ray casting:
  STEP → surface STL via Gmsh, then Möller-Trumbore ray-triangle intersection in
  numpy. No trimesh dependency — requires `gmsh` on PATH and `python3` with `numpy`.
- Stateless HTTP MCP server on port 3018, protocol `2026-07-28`, transport matching
  the rest of the Casys engineering toolchain.
- Three test fixtures generated by build123d: healthy box (40×30×20 mm), L-bracket
  with a clear horizontal overhang, hollow box with a 0.8 mm wall.
